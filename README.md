# 冰箱管家

可运行、可继续修改的本地开发版。包含微信小程序源码、浏览器演示端和 Python SQLite 后端。无需安装 npm 包或 Python 第三方依赖即可运行核心库存流程。

## 微信云开发版

本仓库同时收录了项目的微信云开发版，位于 [`微信云开发版/`](微信云开发版/README.md)：小程序改用微信云开发（云函数 + 云数据库），共 11 页，运行无需本地 Python 后端；照片/视频附件与包装 OCR、食材检测为可选项，需另行部署。部署与验收见 `微信云开发版/docs/`。

根目录这套 Python 后端 + 单页小程序 + 浏览器演示端作为本地演示与离线参考保留，不是最终交付形态。

## 先运行起来

1. 安装 Python 3.10 或更高版本，并确保终端可执行 `python`。
2. 双击项目目录里的 `start.bat`，保持终端窗口打开。
3. 在浏览器打开 **http://127.0.0.1:8765**。
4. 创建家庭并保存个人恢复码。空库存中可点击“加载演示库存”，也可直接添加真实食材。
5. 在“家庭”中取邀请码，另一浏览器或小程序使用“加入家庭”，即可共享库存。

也可在项目目录手动执行：

```powershell
python server/app.py
```

关闭终端或按 Ctrl+C 停止服务。下次启动会保留已录入的数据。若端口被占用，先关闭已运行的服务，或者设置 `$env:PORT='8766'` 后重新启动并访问相应端口。

## 微信开发者工具导入

导入 `miniprogram` 文件夹。项目配置使用 `touristappid` 占位；如果开发工具或功能要求真实 AppID，请换成自己的小程序 AppID。

后端启动后，电脑模拟器使用 `miniprogram/app.js` 中的 `http://127.0.0.1:8765`。项目的 `urlCheck:false` 仅用于本地开发，不是发布配置。

手机上的 `127.0.0.1` 指向手机自身，不是电脑。真机联调需要配置手机可访问的服务地址。正式环境应使用你自己的 HTTPS 域名，并按开发者平台实际要求配置请求域名与小程序权限。微信工具版本和账号能力不同，导入与真机能力须在你的开发者账号下验证。

若只在可信局域网测试，可显式执行：

```powershell
$env:HOST='0.0.0.0'
python server/app.py
```

随后把 `baseUrl` 改为电脑的局域网地址。该选项会让局域网设备访问服务，不适合作为公网发布方式。默认仅监听本机。

## 接入真实识别

不配置服务时，识别任务会明确失败并提示手动录入；演示库存、演示样例不会冒充识别结果。密钥只保存在服务端环境变量，不要写进网页或小程序。

### 默认方式 本地 YOLOv8 食材识别

项目启动时会自动检查并启动同目录下的 `vision` 本地识别服务。满足以下条件时无需额外配置：

- `vision/.venv` 已创建
- `vision/weights/yolov8s.pt` 已下载

> 模型权重（约 520 MB）、训练数据集（约 5 GB）和训练产物（约 240 MB）不纳入 Git 仓库。数据集与训练产物已移到仓库外的 `E:\fridge-keeper-datasets\`，需要评估或重训时按 `vision/README.md` 移回或用目录联接。首次克隆仓库后按 README 下载权重即可运行。

当前本地模型支持照片，以及由后端完成抽帧后的视频帧。小票识别尚未接入本地模型，会明确提示不支持。照片结果会按类别生成待确认候选，数量和日期仍由用户复核。

识别服务使用包含 104 类食材的中国家庭冰箱目录，前端输出以中文名称为准，并过滤酒类、热狗、香料等非目标类别。识别结果会携带中文别名、常用单位和默认冷藏/冷冻位置。

如需关闭自动启动，设置：

```powershell
$env:FRIDGE_DISABLE_LOCAL_VISION='1'
```

如需指定显卡或 CPU，设置 `LOCAL_VISION_DEVICE`，例如 `0` 或 `cpu`。

### 可选方式一 兼容 Chat Completions 的视觉服务

```powershell
$env:VISION_URL='你的完整 chat completions 接口地址'
$env:VISION_MODEL='你实际可用的视觉模型名称'
$env:VISION_KEY='你的服务端密钥'
python server/app.py
```

适配器代码位于 `server/vision.py`，使用 `messages` 中的 `image_url` 图片输入和文本 JSON 输出。接口地址、模型是否支持该格式、图片限制、收费和数据保留政策以你所选择的服务为准。本项目未绑定或购买任何模型。

上传素材会发送到你配置的识别服务。视频先在本地抽帧：处理前 30 秒，每 3 秒抽一帧，最多 10 帧、宽度 960 像素，然后整组发送，要求识别服务跨帧合并候选。抽帧依赖 FFmpeg，安装后确保可从 PATH 调用，或设置 `FFMPEG_PATH` 为可执行文件的绝对路径。

此版去重依赖视觉服务对多帧的判断，没有独立目标跟踪模型。相同包装、遮挡和数量无法确认时必须人工复核，不承诺识别准确率。

### 可选方式二 自定义识别适配服务

设置 `RECOGNITION_URL` 和可选 `RECOGNITION_KEY`。同时配置两种方式时，优先使用自定义服务。

后端向该地址发送 `POST`，请求为：

```json
{"kind":"photo","images":["不含 data URL 前缀的 base64 图片"]}
```

`kind` 为 `photo`、`receipt` 或 `video`。视频请求包含多张 JPEG 帧和 `instruction` 字段。响应为：

```json
{"candidates":[{"name":"番茄","quantity":null,"unit":"个","location":"冷藏","expiry":""}]}
```

不确定的数量返回 `null`，前端要求补填；日期无法确定时返回空字符串；不要把购买日期当成到期日期。最多返回 50 项。后端会验证结果，用户点击确认后才写库存。

## 数据与业务规则

- 默认数据库：`data/fridge.db`。可用 `FRIDGE_DB` 环境变量覆盖路径。
- 备份：先停止服务，再复制该数据库文件。恢复：停止服务，备份当前文件后，以备份文件替换它，再启动。JSON 导出用于查阅，不提供导入恢复。
- 每次入库创建独立批次，同名食材不自动合并。
- 同一提交标识和内容重复请求只入库一次；同一标识换内容会被拒绝。
- 消耗和丢弃填写本次减少量；盘点填写当前剩余量，可填 0。盘点记录的是变化量。
- 并发更新使用版本号和数据库事务；发生冲突时拒绝旧版本，不静默覆盖。
- 仅支持同单位数量运算，不换算袋、克等不同单位。
- 日期按中国标准时间当天 23:59:59 判定；分档为已过期、今天到期、3 天内、7 天内、7 天后、日期未知（“今天到期”按到期日当天计算，不是滚动 24 小时）。
- 日期本身由用户或识别服务填写；本版没有食品安全判定能力。
- 所有成员权限相同。更换邀请码阻止旧码继续邀请，不移除已加入成员。
- 原始图片只在内存中处理；视频临时文件在抽帧后清理。识别任务结果和库存长期保存在数据库。
- 服务重启时，未完成的识别任务标为失败，用户重新上传。网页和小程序可继续查询各自最后一次识别任务。
- 登录会话默认 30 天过期（`FRIDGE_SESSION_DAYS`），过期后需用恢复码重新登录；退出登录立即失效。
- 识别任务默认同时处理 2 个（`FRIDGE_MAX_TASKS`），其余任务保持排队状态；完成或失败的任务保留 7 天（`FRIDGE_TASK_RETENTION_DAYS`），幂等提交记录保留 30 天（`FRIDGE_REQUEST_RETENTION_DAYS`），启动时自动清理。
- 识别候选会带上 `confidence`（0–1，未知为 `null`），供前端提示“识别不确定，请核对”；候选仍需用户确认后才入库。

## 接口速查

除 `/api/auth` 与 `/api/health` 外，请求头均带 `Authorization: Bearer <token>`；写接口采用 JSON。

| 方法 路径 | 主要参数 |
| --- | --- |
| GET /api/health | 无需鉴权 版本 数据库状态 识别服务状态 |
| POST /api/auth | action=create/join/login 对应 name homeName / invite / code |
| GET /api/state | 家庭 成员 在库批次 采购项 最近操作 |
| POST /api/items/add | key 幂等标识 items 数组 |
| POST /api/items/change | id version kind quantity |
| POST /api/shopping/add | name |
| POST /api/shopping/toggle | id |
| POST /api/recognize | kind data 图片或视频 base64 |
| GET /api/task?id=... | 查询所属家庭的识别任务 |
| POST /api/invite/rotate | 空对象 |
| POST /api/demo | 空对象 仅适用于从未录入库存的家庭 |
| POST /api/logout | 空对象 |
