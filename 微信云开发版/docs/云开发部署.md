# 小满冰箱：云开发部署

当前 AppID：`wx8afbc664265f1bc0`。团队：冷鲜栈。

## 1. 开通环境

在微信开发者工具点击“云开发”，以小程序管理员身份开通并创建环境。名称可以用 `xiaoman-fridge`，环境 ID 以平台实际生成的值为准。套餐、试用期、资源点和费用以开通页面为准；代码不会自动购买套餐或开启超额付费。

建议选择适合目标用户的中国大陆环境，并记录控制台展示的地域。云端保存文本型食材资料；本版不上传图片或视频。

## 2. 导入完整工程

导入 **冰箱管家微信小程序** 目录（包含根目录 project.config.json、miniprogram 和 cloudfunctions），即可同时看到小程序和云函数。此前仅导入 miniprogram 的方式也保留配置，但推荐完整工程。

在项目根目录 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\configure-cloud.ps1 -EnvironmentId '替换为真实环境ID'
```

也可手动修改 `miniprogram/config.js` 的 `cloudEnv`。环境 ID 和 AppID 是公开标识，不需要向聊天发送 AppSecret 或其他密钥。

## 3. 建立数据库与权限（必须完成）

打开云开发控制台 → 数据库，创建三个集合：

| 集合 | 用途 |
| --- | --- |
| fridge_users | 账号、同意版本、所属家庭、最近操作的幂等摘要 |
| fridge_homes | 家庭成员、在库批次、采购项、最近操作记录 |
| fridge_invites | 有效邀请码的哈希索引、家庭及有效期 |

**对每一个集合**在权限管理中选择自定义安全规则，填写并保存：

```json
{"read": false, "write": false}
```

规则文件另存于 `database/security-rules.json`。该设置阻止客户端绕过云函数直接读写。云函数使用服务端权限访问数据库，并自行检查微信身份、家庭成员关系和所有者权限。只使用文档 ID 查询，无需手工复合索引。

不要设为“所有用户可读写”，也不要在客户端直接调用 wx.cloud.database 来替代服务端检查。

## 4. 部署云函数

在工具中选定对应云环境，右键 `cloudfunctions/fridgeApi` → “上传并部署：云端安装依赖”。运行时使用支持 Node.js 18 或更高版本的可用环境。若可配置超时，初期建议 20 秒，并在真机测试中确认响应时间。

也可执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\deploy-cloud.ps1
```

依赖已锁定版本，代码通过 `wx-server-sdk` 的 `getWXContext` 获取服务端微信身份。没有自建密码或恢复码，也不需要 AppSecret。`EXPECTED_APPID` 可在云函数环境变量配置；省略时使用当前项目 AppID。

本地 Python 后端、8765 端口和旧启动脚本不参与云开发版运行。

在正式提审前完善 `release.json` 中的账号登记主体、云环境地域和逐项验证记录。团队名称“冷鲜栈”不自动等同于公众平台登记主体，应按后台真实信息填写。


发布检查未通过时，不应宣称已经完成上线。当前脚本不会替你提交审核或发布。

## 运维与容量

每个家庭最多 20 位成员、300 批在库食材、100 项采购清单；操作记录仅保留最近 200 条。库存归零后从在库记录删除。每个账号最多保留最近 24 小时内 400 笔操作回执，过期回执在下次访问时清理；旧请求超过 24 小时被拒绝。每分钟最多 100 次成功请求，作为基础使用限制，不替代平台侧限流。

一个家庭使用一个有明确大小上限的数据库文档，变动和操作记录在事务中原子提交。这适合家庭级并发；若以后拓展大型组织或需要完整历史，需拆分库存集合、分页查询并增加归档策略，不应直接放大单文档上限。

在控制台设置用量/余额告警，观察资源点、函数耗时、错误率和数据库用量。不开启超额付费或套餐到期可能影响服务；超额付费可能产生额外费用，应由账号持有人决定。

通过控制台配置备份/回档与日志保留周期，核实当前套餐是否提供。代码不记录 OpenID、邀请码、食材明细到业务日志。云平台运行日志仍应按实际配置管理。恢复数据库备份需要同时恢复三个集合，恢复后轮换受影响家庭邀请码并复核成员关系。
