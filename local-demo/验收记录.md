# 冰箱管家本地开发版验收记录

验证日期：2026 年 9 月 29 日。

## 自动化测试

运行 `python tests/test_api.py`，10 项测试通过，无跳过。

1. 家庭创建、恢复码登录、退出后令牌失效。
2. 家庭库存和采购项访问隔离。
3. 重复提交只生成一个批次，同一标识变更内容被拒绝，批量错误整体回滚。
4. 盘点剩余量及变动记录、采购状态更新。
5. 邀请加入、两个成员并发扣减仅一次成功、更换邀请后旧码失效。
6. 非有限数、零数量、空批次、无效日期验证。
7. 自定义识别适配器结果解析、不确定数量留空、识别结果不直接入库。
8. 未配置识别服务时明确失败，其他家庭无法查询任务。
9. 使用 FFmpeg 生成测试视频，完成实际抽帧及模拟识别服务调用。
10. Chat Completions 兼容视觉适配器的模拟响应解析。

浏览器和小程序 JavaScript 均通过 Node 语法检查。

## 浏览器交互验证

通过本地浏览器实际执行：创建家庭、显示恢复码、加载样例、手动添加苹果 4 个、消耗 1 个后显示 3 个、添加采购项并标记已买。刷新页面后库存仍保留。

检查桌面布局和手机宽度布局。手机宽度下内容宽度与布局视口宽度一致，没有整页横向溢出；顶部导航可横向滚动。

验收操作保存在独立的预览数据库中，不打包进交付压缩文件。源码包第一次启动为全新数据库。

## 尚未验证与明确边界

- 没有真实视觉服务凭证，未测试模型实际识别准确率、计费、跨帧去重质量；测试使用模拟返回。
- 未登录微信开发者工具、未使用真实 AppID、未在手机微信运行。小程序源码已提供，不能将语法检查等同于真机验收。
- 未进行公网部署或压力测试。默认本机运行，无生产级限流和任务队列。
- 固定菜谱只有浏览器端提供；没有自动日期估算、订阅消息、周报和学习功能。

后续优先验证：真实识别接入 → 微信账号与真机 → 补充业务模块。详细配置见 README.md。
