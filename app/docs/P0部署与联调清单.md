## 3. 部署后接口自检（控制台）

在开发者工具 Console 依次执行，确认返回 `ok: true`：

```js
const call = (action, data = {}) =>
  wx.cloud.callFunction({ name: 'fridgeApi', data: { action, data } }).then(r => r.result)

await call('session')                 // 已登录返回 user/home
await call('recipe.list', { servings: 2 })   // recipes=142，有 ready/almost/inspiration
await call('report.summary', { days: 7 })    // totals/byDay/amount=null
await call('todo.list')                       // expired/urgent/soon/shopping
await call('account.export')                  // items/shopping/events/stats/aliases
await call('alias.list')                      // { items: [], limit: 50 }
await call('reminder.status')                 // ready=false（未配置模板）
```

写操作需要 `key`，例如：

```js
const key = Date.now() + '-deploy-check'
await wx.cloud.callFunction({ name: 'fridgeApi', data: {
  action: 'shopping.add', data: { name: '测试-部署校验' }, key
}})
```

## 5. 微信订阅提醒（待外部输入）

前置：拿到模板详情页的**完整字段编号**（不是关键词顺序）。

1. 配置环境变量：`REMINDER_TEMPLATE_ID`、`REMINDER_FIELDS`、`REMINDER_STATE=trial`
2. 在 `cloudfunctions/fridgeApi/config.json` 增加每小时一次的触发器：

   ```json
   {
     "permissions": { "openapi": ["subscribeMessage.send"] },
     "triggers": [
       { "name": "reminderTimer", "type": "timer", "config": "0 0 * * * * *" }
     ]
   }
   ```

   部署后到云开发控制台确认触发器存在，触发事件包含 `Type: "Timer"`。
3. 设 `REMINDERS_READY=true`，重新部署
4. 真机：进入提醒页 → 微信弹窗同意 → 等待/手动触发定时器 → 检查是否收到一条汇总提醒
5. 验收通过后，把 `release.json` 的 `reminderTemplateConfigured`、`reminderTimerVerified`、`reminderWechatDeliveryVerified` 改为 `true`
