# 智谱照片识别

接口已实现，尚未配置 API Key、启用开关或验证真实照片。官方模型页面将 GLM-4V-Flash 标为免费；微信云函数调用和流量仍消耗云开发额度，不承诺整个应用零成本。

## 配置

仅在 fridgeApi 云函数环境变量中配置 `ZHIPU_API_KEY`；不要发送到聊天、提交 GitHub 或写入小程序。确认账号可调用 glm-4v-flash 且仍免费，完成平台隐私指引后设置 `GLM_VISION_READY=true`。设置云函数超时至少 35 秒；请求自身超时 25 秒。停用时将开关改为 false。

部署后在手机选择照片，点击“智谱识别食材”，同意本次传送后测试。有云存储的媒体功能和本接口独立，`MEDIA_READY` 不需要开启。不会上传到家庭相册，也不需要创建新的数据库集合。

## 行为

- `vision.status` 返回服务开关和本功能同意版本，需已登录。
- `vision.recognize` 接收压缩图片 `imageBase64`、`consentVersion=zhipu-photo-2026-10-27`，不接受外部图片 URL。
- 客户端压缩至不超过 500 KB；服务端验证 JPEG/PNG 文件头、大小、登录和家庭成员身份。
- 每用户每天最多 20 次，间隔至少 15 秒，失败也计入次数。事务保存计数，不保存图片或模型原始回复。
- 固定请求官方 HTTPS 地址和 glm-4v-flash，不自动重试、不切换付费模型。密钥只在服务端使用。
- 只采纳最多 20 个去重名称，丢弃模型返回的数量、日期和置信度。默认单位、存放位置是待用户确认的表单初值，不是视觉推断。
- 用户勾选核对后只能带入草稿，数量留空，最终保存由用户确认。不可用此功能判断食品安全。
- 每次发送前明确告知智谱第三方处理；照片内文字不当作指令。第三方保留策略须核对服务协议，不能声称第三方不留存。

## 验收

自动测试覆盖开关、登录、同意、图片校验、并发限流、格式错误和模型猜测字段过滤。还需使用非敏感测试照片验证真实上游格式、中文响应、限流和真机压缩；测试成功前不标记正式开通。

视频未接入。小票不能仅靠名称候选实现明细录入，还需商品行、数量/单位解析及核对界面。
