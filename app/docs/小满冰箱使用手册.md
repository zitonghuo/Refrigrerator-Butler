# 小满冰箱使用手册

适用版本：2.0.0 云开发版  
更新日期：2026 年 10 月 20 日  
制作团队：冷鲜栈

小满冰箱用于记录家中的食材、查看到期日期、整理采购清单，并让家人共同维护同一份库存。

> 当前为开发预览版，尚未正式发布。已在开发者工具中完成真实云端登录、创建家庭、食材保存和回读验证；手机真机及双微信账号共享、隔离验收尚未完成。本手册按当前代码功能编写，不代表所有功能均已完成真机验收。

## 一、第一次使用

1. 使用有预览权限的微信扫描开发者提供的最新预览码。预览码失效时，请联系开发者重新生成。
2. 在欢迎页点击“阅读隐私说明”。
3. 阅读后，勾选同意选项，点击“同意并使用微信登录”。
4. 选择“创建家庭”或“加入家庭”。
5. 进入“个人中心”，填写家人容易认出的称呼，点击“保存称呼”。

当前使用微信身份区分账号，不需要设置密码，也不读取微信头像、昵称或手机号。再次使用同一微信登录，可访问自己原有的家庭数据。

开发版并非任何微信都能打开。其他人参与测试前，需要具备对应的开发或体验权限；拿到家庭邀请码并不等于获得开发版访问权限。

## 二、页面在哪里

| 页面 | 主要用途 |
| --- | --- |
| 我的冰箱 | 查看库存、按存放位置筛选、搜索食材、查看临期情况 |
| 添加食材 | 填写名称、数量、单位、位置和到期日期 |
| 食材详情 | 修改资料，记录消耗、丢弃或实际剩余量 |
| 采购清单 | 记录待买物品、标记已买、删除采购项 |
| 我的家庭 | 查看成员、邀请家人、管理成员和查看操作记录 |
| 个人中心 | 修改称呼、恢复未确认提交、查看隐私说明、退出或注销账号 |

底部导航可切换库存、采购、家庭和个人中心。点击库存中的食材卡片，可进入详情。

## 三、创建家庭或加入家人

### 创建家庭

在首次登录后的页面选择“创建家庭”，输入名称，例如“我们的小厨房”，点击“创建家庭”。创建成功后进入“我的冰箱”。

### 邀请家人

1. 家庭创建者打开“我的家庭”。
2. 点击“复制邀请码”，自行发送给家人。
3. 家人登录后选择“加入家庭”，粘贴邀请码并提交。
4. 家人进入后，可共同维护库存和采购清单。

邀请码有效期为 7 天。点击“更换邀请码”后，旧码立即失效；已加入的成员不会因此退出。请只把邀请码交给准备加入该家庭的人。

每个账号当前只能加入一个家庭。已在家庭中的账号若要加入另一个家庭，需先处理原家庭关系并退出。

### 成员与管理权

普通成员可以管理共享食材和采购清单。家庭创建者还可以更换邀请码、移除成员和转让管理权。

- **移除成员**：该成员将失去家庭访问权限，同时更换邀请码。
- **转让管理权**：对方成为新的管理者，原管理者仍留在家庭中。
- **退出家庭**：退出后无法继续查看该家庭数据。有其他成员时，创建者需要先转让管理权。
- **最后一位成员退出**：家庭库存、采购清单和操作记录会被删除，请先确认。

## 四、把食材放进冰箱

1. 打开“我的冰箱”，点击“＋添加”或“添加第一份食材”。
2. 填写以下信息。
3. 若要一次录入多份，点击“＋再加一项”。
4. 点击“确认入库”，保存成功后回到库存页。

| 字段 | 填写方法 |
| --- | --- |
| 名称 | 例如鸡蛋、番茄、鸡胸肉 |
| 数量 | 例如 6、2、0.5，应大于 0 |
| 单位 | 例如个、袋、盒、千克 |
| 存放位置 | 冷藏、冷冻或常温 |
| 到期日期 | 按包装或实际记录填写；不清楚时可留空，稍后补充 |
| 日期来源 | 手动填写、包装标注或自行估算 |

同名但到期日期不同的食材，建议分开录入。例如今天买的牛奶和上周买的牛奶，各记一项，便于先用临期批次。

一次最多添加 20 项。未提交内容会在本机保存为草稿；成功入库后清除草稿。退出登录、退出家庭或注销账号会清除相关本机草稿。

## 五、查看库存与日期

- 点击“全部、冷藏、冷冻、常温”查看对应位置的食材。
- 在搜索框输入名称的一部分，例如“鸡”，查找相关食材。
- 使用临期筛选查看需要优先处理的食材。
- 家人操作后，可以下拉刷新页面，获取云端最新数据。

日期标签包括“已过期”“今天到期”“3 天内”“7 天内”“7 天以上”和“日期待补”。“今天到期”按到期日当天计算（以当天 23:59:59 为界），不是滚动 24 小时。这些标签按填写的日期计算；首页“3 天内到期”数量不包含已过期食材，临期筛选会包含已过期项。

**日期提示仅用于库存管理，不是食品安全判断。** 当前版本不会自动识别食材新鲜程度，也没有接入微信订阅消息推送；请主动打开小程序查看。

## 六、记录吃掉、丢弃和剩余数量

在库存页点击食材，进入详情。

| 操作 | 应输入什么 | 示例 |
| --- | --- | --- |
| 记录消耗 | 本次用掉的数量 | 原有 6 个鸡蛋，用掉 2 个，输入 2，剩余 4 个 |
| 记录丢弃 | 本次丢掉的数量 | 丢掉 1 个，输入 1 |
| 盘点剩余量 | 现在实际还剩多少 | 系统显示 4 个，实际剩 3 个，输入 3 |

“盘点剩余量”填写的是最终剩余数，不是减少的数量。库存变为 0 后，该批食材会从在库列表移除。

点击“修改资料”可以修改名称、单位、存放位置和到期日期。数量变化请使用上面的三种操作。

新增购买的食材，建议从“添加食材”新建批次，以便区分日期。发生错误时，可通过盘点纠正现有批次数量；当前没有一键撤销功能。

食材详情显示该食材近期记录；“我的家庭 → 查看操作记录”可查看家庭近期操作。家庭最多保留最近 200 条记录，不适合作为长期完整账本。

## 七、使用采购清单

1. 打开底部“采购清单”。
2. 输入要买的物品名称并添加，例如“鸡蛋一盒”。
3. 买到后，将该项标记为已买；再次切换可以恢复为待买。
4. 不再需要的项目，可以点击删除并确认。

同一家庭共享这份清单。**标记已买不会自动增加冰箱库存**，购买后仍需在“添加食材”中登记数量和日期。

## 八、个人中心

- **保存称呼**：修改家庭成员列表中显示的名字。
- **恢复提交**：网络中断导致某笔操作结果不确定时，用原操作编号核对提交，避免重复记账。
- **隐私说明**：查看数据使用说明。
- **复制联系邮箱**：复制邮箱后，可使用自己的邮件应用联系团队。
- **退出登录**：清除本机登录状态和草稿，云端数据保留。
- **注销账号**：删除账号，相关共享操作记录匿名化；最后一位家庭成员注销时，家庭数据也会删除。此操作不可撤销。有其他成员的家庭创建者，应先转让管理权。

## 九、遇到问题怎么办

| 现象 | 处理方法 |
| --- | --- |
| 预览码无法打开或已经失效 | 使用具备权限的微信，并向开发者索取最新预览码 |
| 提示连接未完成 | 检查网络，重新同步；若出现未确认操作，进入个人中心“恢复提交” |
| 提示还有一笔操作未确认 | 先恢复该笔提交，再进行其他修改，不要反复新增相同食材 |
| 恢复请求超过 24 小时 | 旧请求会被拒绝；刷新并核对实际库存后，再决定是否重新操作 |
| 家人修改后自己没看到 | 下拉刷新页面，确认双方加入的是同一家庭 |
| 提示记录已变更或版本冲突 | 刷新后按最新数量重新操作，避免覆盖家人的修改 |
| 邀请码无效 | 检查是否复制完整、是否过期或已更换；请创建者提供新码 |
| 找不到某份食材 | 清除搜索和筛选条件；核对是否已经消耗完、丢弃完或盘点为 0 |
| 提示云服务未配置或服务异常 | 联系开发者核实云环境和部署状态 |

云端服务正常时，使用小程序不需要开发者的电脑一直开机，但需要网络连接及可用的云开发资源。

## 2.2.0 新功能

首页、个人中心都有“今天的冰箱安排”：

- 今日待办：查看已过期、今天到期、3 天内到期食材和未完成采购。点击食材进入详情。
- 做什么菜：按已有且未过期的食材匹配固定菜谱，选择用餐人数；确认后可把缺少食材加入采购清单。实际份量仍需自行确定。
- 周报/月报：切换近 7 天或近 30 天（含今天），按单位分别显示入库、消耗、丢弃与盘点。历史记录不完整会明确标注，不计算未记录的金额。
- 微信到期提醒：当前等待公众平台模板配置。开通后点击按钮并在微信中同意，可登记未来 7 天内的一次临期提醒；收到后需要再次订阅。不是一次同意后永久推送。
- 保存到手机相册：拍摄预览后主动点击保存，微信可能请求权限；保存成功后退出页面也不会丢失相册文件。

默认关闭电脑直连识别，避免普通用户访问不了本机地址。识别服务部署及手机两账号验收仍需完成。
