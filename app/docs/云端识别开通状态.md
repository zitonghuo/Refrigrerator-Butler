- 小程序拍摄、预览和手动确认入口。

## 开通前仍需完成

1. 确认账号可用的云托管服务、试用额度、到期时间及费用上限。不能把新用户免费额度视为本账号已领取。
2. 核实图片存储权限可配置，完成私有权限、保留期和清理任务。保持 `mediaCloudEnabled`、`MEDIA_READY` 关闭直到验证通过。
3. 准备模型：当前 `vision/weights` 只有 `.gitkeep`。默认 hybrid 后端需要 `yolov8s.pt` 与 `fruits_vegetables_yolov8s_v1.pt`；必须核查下载来源、许可、文件摘要和实际识别效果，不能把空目录镜像当作可运行服务。
4. 在可用的构建环境构建镜像并测试。当前电脑未检测到 Docker，两个容器尚未完成构建验证；PaddleOCR 的模型下载和冷启动也须验证。
5. 配置 HTTPS、仅服务端持有的认证令牌、请求大小和并发限制。分别连接 `VISION_URL/VISION_TOKEN` 与 `OCR_URL/OCR_TOKEN`，令牌不提交 GitHub。
6. 用测试照片验证真实结果、失败提示和删除流程，更新隐私说明后再开启小程序入口。照片识别只给建议，不自动修改库存。
