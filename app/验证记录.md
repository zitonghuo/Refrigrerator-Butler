# 小满冰箱云开发版验证记录

更新日期：2026-10-27。

## 2026-10-27 P1：家庭别名与日期估算

- 新增 `alias.list / alias.set / alias.remove`：别名由用户手动设置，无内置词典、不自动学习；每个家庭独立，上限 50 条，`from === to` 或形成循环时拒绝。
- `item.add` 命中别名时替换为最终名称并写入 `aliasOf`；链式别名最多解析 5 跳；`account.export` 包含 `aliases`。
- 日期估算：`source=estimate` 且 `expiry` 为空时，按名称规则 + 存放位置补日期（叶菜 3 天、根茎 14、肉类冷藏 2/冷冻 90 等，默认冷藏 7 / 冷冻 60 / 常温 3），写入 `estimateBasis`；用户填写的日期优先，切回手动来源时只清除依据、保留日期。
- `npm test` 54 项通过（新增别名 6 项、估算 4 项），`check-project` 11 页通过。
- 未做真机验证；别名管理页与"估算日期"提示由前端接入。

## 2026-10-27 数据导出与依赖复核

- 新增只读动作 `account.export`：导出当前家庭的食材、采购、操作记录与按日统计；不包含邀请码、OpenID 或会话令牌，不需要幂等 key。前端保存 JSON 文件即可。
- 依赖复核：`wx-server-sdk 4.0.2` 存在 6 项传递依赖告警（axios 0.27.2、lodash.set/unset），上游无修复版本；降级到 2.5.3 会破坏事务与 `throwOnNotFound` 用法，不采用。当前用法不接收用户 URL、不拼属性路径，判定为已接受风险，详见 `docs/依赖审计.md`。
- `release.json`：`cloudSdkDependencyReview` 置为 `true`，并记录接受理由；其余真机、双账号、隐私、备案仍为 `false`。
- `npm test` 44 项通过（新增导出 3 项），`check-project` 11 页通过。

## 2026-10-24 开发调试：小程序直连本机识别服务

- 新增 `miniprogram/utils/vision.js`：把所选照片读成 base64 后直接 `wx.request` 到 `config.visionUrl`，不经过云存储/云函数，字段收敛后返回候选。
- 照片页在本地预览模式下增加“用本机模型识别”；结果只进入库草稿，不写库存、不上云。
- `project.config.json` 的 `urlCheck` 改为 `false` 以便本机 HTTP 调试；`check-project` 只在 `--release` 时强制要求 `urlCheck=true` 且 `visionUrl` 为空。
- 本机服务实测：`/health` 正常（CPU），西瓜样例返回 3 个候选（苹果 0.378 / 西瓜 0.215 / 胡萝卜 0.175），冷启动约 10 秒。
- `npm test` 41 项通过。
- 边界：仅开发者工具或同局域网真机可用；发布前必须清空 `visionUrl`、恢复 `urlCheck`，正式识别仍走云函数 + HTTPS 服务。
